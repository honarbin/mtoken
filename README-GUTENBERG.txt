نسخه v9 — Gutenberg واقعی و قابل تبدیل به بلاک

روش استفاده:
1. فایل gutenberg.css را یک بار در نمایش > سفارشی‌سازی > CSS اضافی یا فایل CSS قالب قرار دهید.
2. محتوای فایل صفحه موردنظر را در ویرایشگر وردپرس، حالت ویرایش کد (Code editor)، جای‌گذاری کنید.
3. هر بخش با بلوک‌های جداگانه wp:html ساخته شده است و نباید کل فایل را داخل یک بلوک HTML معمولی قرار دهید.
4. بعد از بازگشت به ویرایشگر دیداری، هر بخش به‌صورت بلوک HTML مستقل دیده می‌شود.

نکته: این نسخه برای جلوگیری از خطای «تبدیل به بلاک» از ساختار رسمی Gutenberg استفاده می‌کند.
