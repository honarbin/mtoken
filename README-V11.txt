نسخه v11 - اصلاح مشکل لود صفحات و استایل

مشکل نسخه قبل:
1) پیش‌نمایش با fetch کار می‌کرد و در بازکردن مستقیم با file:// صفحات لود نمی‌شدند.
2) Gutenberg به‌صورت خودکار CSS اختصاصی صفحات را بارگذاری نمی‌کند.
3) فایل gutenberg.css فقط CSS پایه را import می‌کرد و CSS صفحه‌ها در وردپرس enqueue نشده بود.

اصلاحات:
- پیش‌نمایش اکنون محتوای صفحات را داخل خود فایل دارد و بدون سرور محلی نیز باز می‌شود.
- gutenberg.css اکنون برای تست، CSS همه صفحات را import می‌کند.
- برای سایت واقعی، mtoken-base.css و mtoken-components.css را عمومی و فقط CSS صفحه مربوطه را با functions.php بارگذاری کنید.
- فایل wordpress-enqueue-example.php برای این کار اصلاح شده است.

نکته: اگر HTML را در Gutenberg می‌چسبانید، CSS باید از طریق Additional CSS، قالب یا افزونه بارگذاری شود؛ HTML به‌تنهایی استایل اختصاصی را همراه خود نمی‌آورد.
