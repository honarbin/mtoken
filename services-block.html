پرسش‌های متداول

قبل از درخواست راه‌اندازی

من نمی‌دانم سامانه از دستینه استفاده می‌کند یا Java؛ چه کار کنم؟
نیازی نیست خودتان روش فنی سامانه را تشخیص دهید. کافی است نام سامانه را اعلام کنید تا مسیر موردنیاز برای استفاده از گواهی بررسی شود و بر اساس آن راه‌اندازی انجام شود.
آیا همه سامانه‌ها به دستینه نیاز دارند؟
خیر. دستینه تنها یکی از روش‌های استفاده از گواهی دیجیتال است. بعضی سامانه‌ها از Java استفاده می‌کنند و برخی دیگر ممکن است به Middleware یا نرم‌افزار و تنظیمات اختصاصی نیاز داشته باشند.
برای سامانه ستاد اگر Unable to Launch Application نمایش داده شود، چه کاری لازم است؟
در سامانه‌هایی که اجرای بخشی از فرآیند به Java وابسته است، نسخه Java و تنظیمات محیط اجرا می‌تواند اهمیت داشته باشد. در این شرایط محیط Java و تنظیمات لازم متناسب با سامانه بررسی می‌شود.
برای بانک ملت هم می‌توانید محیط Java را آماده کنید؟
در مواردی که فرآیند موردنظر از Java استفاده می‌کند، نسخه و تنظیمات محیط Java بررسی و برای اجرای صحیح سامانه آماده می‌شود.
اگر سامانه من در لیست شما نیست چه کنم؟
کافی است نام سامانه و در صورت امکان مدل یا نوع توکن خود را اعلام کنید. مسیر فنی موردنیاز بررسی می‌شود و در صورت امکان، راه‌اندازی آن انجام خواهد شد.
آیا باید خودم نرم‌افزارها را دانلود و نصب کنم؟
اگر برای دریافت خدمت راه‌اندازی اقدام کنید، کارشناس بر اساس سامانه و روش موردنیاز، نرم‌افزارها و تنظیمات لازم را بررسی و آماده می‌کند.
آیا برای راه‌اندازی باید کلید خصوصی گواهی را ارسال کنم؟
کلید خصوصی اطلاعات محرمانه‌ای است و نباید بدون ضرورت در اختیار دیگران قرار گیرد. در راه‌اندازی توکن، هدف آماده‌سازی محیط لازم برای استفاده از گواهی است.
