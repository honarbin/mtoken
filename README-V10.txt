نسخه ۱۰ قالب‌های Gutenberg سایت mToken

تغییرات اصلی:
- CSS یکپارچه و CSS اختصاصی هر صفحه از هم جدا شده است.
- به‌جای بارگذاری حدود ۲۱۰ کیلوبایت CSS برای همه صفحات، فقط CSS همان صفحه را بارگذاری کنید.
- کلاس‌های قبلی حفظ شده‌اند تا دکمه‌ها و رفتار ظاهری صفحات از بین نرود.
- فونت خارجی Google Fonts از CSS حذف شده است؛ فونت Vazirmatn را در وردپرس به‌صورت محلی یا از طریق قالب بارگذاری کنید.
- فایل gutenberg-all-pages.css فقط برای پیش‌نمایش و تست همه صفحات است.

ساختار پیشنهادی:
assets/css/mtoken-base.css
assets/css/mtoken-components.css
assets/css/pages/[page].css

نحوه استفاده:
۱) mtoken-base.css و mtoken-components.css را یک‌بار در سایت بارگذاری کنید.
۲) برای هر صفحه فقط فایل اختصاصی همان صفحه را بارگذاری کنید؛ نمونه: pages/services.css
۳) محتوای فایل services-block.html را در ویرایشگر Gutenberg و بلوک «HTML سفارشی» قرار دهید.
۴) برای صفحات دیگر نیز فایل block متناظر را استفاده کنید.

نکته SEO:
عنوان SEO، توضیحات متا، نشانی یکتا و اسکیما باید در افزونه SEO یا تنظیمات وردپرس تعریف شوند. پیشنهادها در فایل SEO-SETTINGS.txt آمده است.
